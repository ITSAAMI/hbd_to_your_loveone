# Birthday Wish Creator 🎈

A premium, interactive web application that allows you to design a personalized, memorable digital birthday journey for someone special. 

## ✨ Features
* **Multi-Step Creator Flow**: An intuitive, step-by-step UI to build the birthday surprise.
* **Personalized Details**: Customize the recipient's name, nickname, photo, and a personalized birthday message.
* **Secret Code Lock (Optional)**: Add an element of surprise by requiring a secret passphrase to unlock the birthday message.
* **Interactive Experience**: Features a beautifully animated reveal sequence with floating hearts, interactive balloon popping, falling confetti, and fireworks.
* **Fully Responsive**: Built to look fantastic on desktops, tablets, and mobile devices.

## 🚀 Live Demo
Experience the creator here: [https://itsaami.github.io/hbd_to_your_loveone/](https://itsaami.github.io/hbd_to_your_loveone/)

## 🛠️ Built With
* **HTML5**: For semantic structure.
* **CSS3**: For advanced styling, glassmorphism, fluid typography, and CSS animations.
* **Vanilla JavaScript**: For logic, state management (using `sessionStorage`), and DOM manipulation.

## 📂 Project Structure
* `index.html`: Contains the markup for both the creator flow and the final interactive experience.
* `style.css`: All the styling, animations, and responsive media queries.
* `script.js`: Handles the multi-step form validation, state management, and the interactive animations (fireworks, confetti, balloon pop).
* `assets/`: Contains media assets (like the background song and default images).

## 💻 How to Run Locally
1. Clone the repository.
2. Open `index.html` in your favorite web browser. (No build tools or local servers are strictly required!)
